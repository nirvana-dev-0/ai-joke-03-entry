# ai-joke-03

A program that writes one joke about AI coding agents to `/output/entry.txt`, for the make.fun bounty [Make the AI judge laugh](https://make.fun/bounty/ai-joke-03).

Run it locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```

The joke is a fixed string: the program writes the same bytes on every run.
